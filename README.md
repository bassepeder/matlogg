# Matlogg

Food and calorie diary for Norway. Installable web app, data stays on the device.

- Search 2,100+ foods from Matvaretabellen, offline
- Search and scan Norwegian grocery products via VetDuAt, with Open Food Facts as barcode fallback
- Custom foods, recipes and quick add
- Calorie and macro goals, month calendar
- Share foods and recipes as links
- JSON backup and restore

## Install

Open [bassepeder.github.io/matlogg](https://bassepeder.github.io/matlogg/) and choose **Add to Home Screen** (Safari) or **Install app** (Chrome).

To search and scan Norwegian grocery products, deploy the [VetDuAt proxy](proxy/README.md) and paste its URL in Settings.
